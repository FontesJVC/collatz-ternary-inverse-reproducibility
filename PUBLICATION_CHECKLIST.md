# GitHub + Zenodo publication checklist

- [x] Public GitHub repository created.
- [x] MIT License selected.
- [x] Repository-specific `CITATION.cff` prepared.
- [x] Zenodo metadata file prepared.
- [ ] Push the prepared repository contents to GitHub.
- [ ] Connect the public GitHub repository to Zenodo.
- [ ] Create `paper1-v1.0.0` after the Paper 1 preprint URL is known.
- [ ] Archive that release on Zenodo and add its DOI to Paper 1.
- [ ] Create `paper2-v1.0.0` when Paper 2 is ready for its own frozen snapshot.
- [ ] Archive that release on Zenodo and add its DOI to Paper 2.
